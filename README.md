# Unity Pixel RPG

A feature complete action RPG prototype demonstrating core game development systems

## 🎮 Implemented Features

### Core Gameplay Systems
- **Enemy Respawning**: Infinite skeleton respawn at designated points, creating continuous combat challenges
- **Real-time UI**: Live updating kill counter and game timer displaying player progress
- **Health & Game States**: Complete health management system with game over triggers

### Animation & Character Control
- **Player Animation System**: Smooth transitions between idle, movement, attacking, and jumping states
- **Character State Management**: Robust handling of player actions and animations

### UI/UX Systems
- **Dynamic Game Over Screen**: Context aware UI that appears upon character death
- **Interactive Restart System**: One click scene reset functionality
- **Live Stat Tracking**: Real time updates for kills and playtime

## 🛠 Technical Implementation
- Built with Unity Engine and C#
- Utilized Unity's UI System for HUD elements
- Implemented Animator Controllers for character animations
- Developed scene management and game state handlers
